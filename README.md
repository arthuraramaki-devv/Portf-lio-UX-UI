# Portf-lio-UX-UI

Este repositório apresenta um protótipo de portfólio pessoal, desenvolvido inicialmente no Figma, com o objetivo de explorar ideias de design, identidade visual e estruturação de uma futura página pessoal.

O projeto reúne algumas informações sobre mim, Arthur, apresentadas de uma maneira mais criativa e, em alguns momentos, propositalmente “sensacionalista”. A ideia é experimentar diferentes formas de apresentar minha trajetória, habilidades e interesses, sem necessariamente tratar todo o conteúdo como uma representação formal ou definitiva.
Mais do que apenas criar um portfólio, este pequeno projeto representa uma oportunidade de praticar e aperfeiçoar meus conhecimentos em Design e Front-end.
